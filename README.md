# 🩺 MediAI – Smart Health & Task Management App

MediAI is an intelligent and user-friendly Android application developed to help users manage their daily health routines, medications, and personal wellness activities in one centralized platform. The application acts as a digital healthcare assistant by combining medicine reminders, health tracking, task management, and performance monitoring into a clean and responsive mobile experience.

Designed with simplicity and accessibility in mind, MediAI supports users of all age groups by reducing missed medications, improving routine consistency, and encouraging healthier daily habits. The app focuses on both productivity and healthcare management, making it easier for individuals to stay organized and maintain their well-being.

---

# ✨ Features

## ⏰ Smart Medicine Reminders

* Schedule medicine reminders with date and time.
* Receive timely notifications and alerts.
* Avoid missing important medications.
* Supports recurring reminders for daily routines.

## 📋 Health Task Management

* Create, update, and manage daily health-related tasks.
* Assign priorities and due times to tasks.
* Organize routines efficiently through an intuitive interface.
* Track completed and pending activities.

## 📊 Health Performance Tracking

* Monitor health habits and routine consistency.
* View personal progress and performance insights.
* Analyze completed health tasks over time.
* Encourage better lifestyle discipline and productivity.

## 🔔 Notifications & Alerts

* Instant notifications for medicines and scheduled tasks.
* User-friendly alert system integrated into the app flow.
* Keeps users informed and organized throughout the day.

## 👤 User Authentication System

* Secure user signup and login functionality.
* Personalized user profiles and account management.
* Firebase Authentication integration for secure access.

## ☁️ Firebase Integration

* Real-time data storage and synchronization.
* Cloud-based health task management.
* Secure and scalable backend support.

## 🎨 Modern UI/UX Design

* Clean, responsive, and easy-to-use interface.
* Soft healthcare-inspired color palette.
* Designed for accessibility and smooth user experience.
* Mobile-friendly layouts with modern Android components.
